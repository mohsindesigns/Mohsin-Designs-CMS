# Service Page Auditor (Quality & Architecture Audit)

## Objective
Conduct a comprehensive post-implementation audit to guarantee elite code quality, semantic SEO, responsive UI consistency, and performance.

## Audit Criteria
1. **Semantic HTML & SEO**: Verify single `<h1>`, proper heading cascade (`<h2>`, `<h3>`), meta/schema data, and accessible ARIA attributes.
2. **UI & UX Quality**: Audit visual consistency, spacing, responsive flex/grid layouts, contrast, and micro-interactions.
3. **Performance**: Check image optimization (Next.js `Image` priority/sizes/placeholders), bundle impact, and memoization.
4. **Code Quality**: Check for dead code, console logs, duplicate style definitions, and clean component organization.
5. **Final Sign-off**: Deliver an itemized audit summary covering strengths, fixed items, and confirmed stability.
